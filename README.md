<h1 align="center"> GenuineWinOffice-Checker </h1>

<p align="center"> English: A tool for scanning and assessing the integrity of Windows and Office licenses using C#. Replicates the methods used to detect KMS, HWID, KMS38, Ohook cracks and system tampering. </p>

<p align="center"> Vietnamese: Công cụ quét và đánh giá tính toàn vẹn bản quyền Windows và Office bằng C#. Tái hiện phương pháp giám định phát hiện vết bẻ khóa KMS, HWID, KMS38, Ohook và can thiệp hệ thống. </p>

## ✨ Key Features

* **System Diagnostics**: Checks activation status, background services, and Registry in real time via C# WMI APIs.

* **Modern Fluent Interface**: Integrates the `Wpf.Ui` library, automatically adapting Windows themes and optimizing the user experience.

* **Performance Optimization**: Completely replaces old Batch scripts, improving stability and reducing scan time.

* **Professional Packaging**: Integrates the `Setup.exe` installer to automate the installation and uninstallation process.

## 🚀 Download & Install

You can download the pre-packaged version directly from **[Releases](../../releases)**:

1. Download the `GenWinOffice.installer.x64.exe` file.

2. Run the installer and follow the on-screen instructions.

3. Open the application directly from the **Start Menu** or the icon on the **Desktop**.

## 🛠️ Compiling from Source Code

### System Requirements
* **Operating System**: Windows 10/11 (64-bit)

* **Tools**: Visual Studio 2026 (with *.NET desktop development* workload installed)

* **SDK**: .NET 10.0 SDK

### Steps

1. Clone the repository to your machine:

```bash

git clone https://github.com/thebinhdx/GenWinOffice.git

```
2. Open the `GenWinOffice.slnx` file using Visual Studio 2026.

3. Press `F5` to run debug or select `Build > Build Solution` (`Ctrl + Shift + B`) to compile the project.
